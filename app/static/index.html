AI Technical Interview Agent

An intelligent, voice-enabled evaluation platform designed to conduct rigorous, personalized technical interviews for AI Cohort graduates & software engineers.

🎯

Why This Platform Was Built

Standard AI interviewers ask generic questions without evaluating true depth. Our agent builds a personalized interview plan by cross-referencing candidate mission histories against a 31-day AI engineering curriculum. It actively probes shallow answers with dynamic follow-ups, tests code tradeoffs, and produces structured evaluation reports.

📊

Curriculum Plan Generator

Deterministically maps mission records to test Depth (passed days), Fundamentals (3+ attempts), and Awareness (skipped days).

🤖

Dual-Role LLM Engine

Separates Interviewer (conversational persona) from Evaluator (rubric scoring 1–5 in JSON) to ensure objective evaluation.

🎙️

Real-Time Voice Engine

Full Speech Recognition (mic), Web Speech Synthesis (voice accents), real-time audio canvas visualizers, and sound effects.

📈

Structured Radar Reports

Generates detailed final evaluation reports with Chart.js mastery spectrum radar graphs, strengths, gaps, and PDF/Markdown exports.
